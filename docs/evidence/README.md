# Evidence provenance

These files are **recorded outputs** of real runs, kept unchanged as historical evidence. They were
generated by `scripts/refresh_evidence.sh` from the application code at commit **`8e8f7cc`**
(2026-09-26), on synthetic data only.

| Artifact | What it is |
|---|---|
| `test_results.txt` | `pytest -v` with Flask installed: 88 passed, 301 subtests passed |
| `unittest_stdlib_only.txt` | `python3 -m unittest` without any install: 88 collected, 7 Flask tests skipped, 81 run and passed |
| `demo_story_output.txt`, `demo_exports/` | `python3 -m rcw demo` output and the exported statements / control reports |
| `benchmark.json` (and generated `../08_benchmark.md`) | 10,000-event benchmark, environment and timings of that run |
| `e2e_results.json`, `e2e_run.txt`, `screenshots/` | Playwright browser run: 19 checks and the screenshots |
| `ci_run.json` | the GitHub Actions run that had completed when the evidence was built |
